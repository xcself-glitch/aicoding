# ETHUSDT永续合约高频交易策略

## 策略概述

- **交易标的**: ETHUSDT 永续合约
- **杠杆倍数**: 10倍固定杠杆
- **时间周期**: 15分钟K线（主周期）+ 5分钟K线（辅助）
- **策略类型**: 日内反转捕捉

## 核心逻辑

### 1. 入场信号（多指标共振）

**做多条件（价格低位+反转信号）：**
- RSI < 30（超卖）或 出现底背离
- KDJ 低位金叉
- MACD 金叉或红柱扩大
- 价格触及布林带下轨
- 成交量放量确认
- 日内价格处于低位区间（<25%）

**做空条件（价格高位+反转信号）：**
- RSI > 70（超买）或 出现顶背离
- KDJ 高位死叉
- MACD 死叉或绿柱扩大
- 价格触及布林带上轨
- 成交量放量确认
- 日内价格处于高位区间（>75%）

### 2. 收益目标（与价格位置相关）

| 价格位置 | 做多目标 | 做空目标 | 杠杆收益 |
|---------|---------|---------|---------|
| 低位区间 (<25%) | 2.5% | - | 15-25% |
| 中间区域 (25%-75%) | 1.5% | 1.5% | 8-15% |
| 高位区间 (>75%) | - | 2.5% | 15-25% |

### 3. 风险控制

- **止损**: 0.8%（基础）~ 1.5%（最大）
- **移动止盈**: 盈利超过1%后，回撤0.5%止盈
- **仓位管理**: 根据信号强度动态调整（0.5-1.0倍标准仓位）
- **交易冷却**: 每次交易后15分钟冷却期
- **日交易限制**: 最多10笔交易/日

## 技术指标配置

| 指标 | 参数 | 用途 |
|------|------|------|
| RSI | 14周期 | 超买超卖判断 + 背离检测 |
| KDJ | 9,3,3 | 金叉死叉信号 |
| MACD | 12,26,9 | 趋势确认 |
| 布林带 | 20,2 | 价格极端位置判断 |
| 成交量 | 20周期均线 | 信号确认 |

## 使用方法

### 1. 安装依赖

```bash
pip install numpy pandas requests
```

### 2. 测试策略

```bash
cd skills/eth-trading

# 获取实时数据并生成信号
python3 scripts/eth_trading_bot.py --once

# 回测（最近7天）
python3 scripts/eth_trading_bot.py --backtest 7

# 持续运行（每分钟扫描）
python3 scripts/eth_trading_bot.py --interval 60
```

### 3. 飞书通知

如需启用飞书通知，请设置环境变量：

```bash
export FEISHU_WEBHOOK="your_webhook_url"
```

## 信号评分机制

每个指标贡献一定权重，总分100分：

- RSI: 20%
- KDJ: 20%
- MACD: 15%
- 布林带: 15%
- 成交量: 15%
- 价格位置: 15%

**入场门槛**: 70分以上
**强信号**: 85分以上（高优先级通知）
